# Installation

## BLOGFA Theme

1. Sign in to the BLOGFA administration panel.
2. Open the template editor.
3. Select one of the files inside the `themes` directory.
4. Copy the complete HTML source.
5. Replace the existing BLOGFA template.
6. Save the template.
7. Open the blog and verify the desktop and mobile layouts.

## Content Blocks

Files inside the `content` directory are standalone HTML fragments.

They can be inserted into:

- BLOGFA posts
- custom BLOGFA pages
- static HTML pages
- compatible CMS editors

## External Images

Several content files use images hosted on:

`https://didactic.ir`

Replace these URLs if the image host changes.

## Customization

The primary interface color used by the modern theme is:

`#0091DC`

Search for this value in the template to change the main accent color.
