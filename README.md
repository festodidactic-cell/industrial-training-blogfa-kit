# Industrial Training BLOGFA Kit

A collection of responsive BLOGFA themes and reusable HTML content blocks designed for Persian industrial automation and technical training websites.

The repository combines complete BLOGFA templates with standalone HTML sections that can be reused inside posts and custom pages.

## Features

- Persian RTL layouts
- BLOGFA template compatibility
- Responsive desktop and mobile design
- Lightweight HTML, CSS and JavaScript
- Industrial automation focused UI
- Reusable content sections
- Inline components suitable for BLOGFA posts
- Image-based educational and promotional layouts
- PLC, pneumatics, hydraulics and energy-management content
- Responsive navigation and content cards
- Optional image slider
- SEO-friendly markup
- No frontend framework required

## Content Blocks

The `content` directory contains standalone HTML sections that can be pasted into BLOGFA posts or custom pages.

The blocks include company introduction, training-value comparisons, PLC training pages, energy-management content, training-needs analysis, international-career training pages, historical content and reusable call-to-action sections.

## Installation

Open the desired theme file and copy its complete contents into the BLOGFA template editor.

Individual files from the `content` directory can then be inserted into BLOGFA posts or static pages as required.

## Notes

Some components reference externally hosted images and website URLs. Those URLs can be replaced without modifying the overall layout.

The project intentionally avoids large JavaScript frameworks so that the templates remain suitable for lightweight BLOGFA environments.
